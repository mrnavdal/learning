# Mission: Pass the Toptal screening process (Flutter / mobile track)

## Why
Get accepted into the Toptal network as a Flutter/mobile engineer — unlocking
higher-rate, international, remote contracts than the local market offers.
This is not "learn Flutter better"; the user has ~8 years of it. This is
about surviving a specific 5-stage filter that tests things day-to-day
product work never exercises: algorithmic speed under a clock, articulating
framework internals out loud, and doing all of it in English.

## Success looks like
- Solves a Codility-style easy problem in ≤10 min and a medium in ≤25 min,
  in JavaScript, at optimal complexity, without hints
- Explains Flutter internals from mechanism (widget/element/render tree,
  keys, const, rebuild vs repaint, isolates, platform channels) and survives
  5 layers of follow-up without stalling
- Designs a mobile-facing system out loud: offline-first sync, conflict
  resolution, caching, API shape for flaky networks, auth on device
- Delivers a 60-second self-pitch and 3 behavioural answers fluently in English
- Ships a test project with architecture, tests, README and clean git history
  that reads as senior work

## Constraints
- **5–8 hours per week** (evenings + weekend). The plan must survive a bad week.
- Not yet applied — the clock is ours to set. Target: apply in ~12 weeks,
  gated on objective criteria (see PLAN.md), not on feeling ready.
- **Language: hybrid.** Teaching and explanation in Czech; drills, think-aloud,
  mock interviews and written answers in English, because that is how the
  real process runs.
- Algorithms: school-level, long faded. No LeetCode habit. Start from patterns,
  not from problem count.
- Dislikes video learning. Interactive components with tight feedback loops.
- Depth style: one topic = an arc of lessons. The learner must be able to
  derive, not recite.

## Out of scope
- Backend depth for its own sake — `node-backend/` owns that track. Backend
  material appears here only where the Toptal funnel tests it (mobile-facing
  system design).
- Non-Flutter mobile (native iOS/Android, React Native).
- Post-acceptance concerns (finding clients, rate negotiation) until accepted.
